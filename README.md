# AI Language Translator 🌍

## About the Project
AI Language Translator is a Python-based web application developed using Streamlit.

It helps users translate text between five different languages.

## Features
- Five language options
- Source and target language selection
- Text translation
- Translation result display
- Simple and user-friendly interface

## Technologies Used
- Python
- Streamlit
- Requests
- Translation API

## How to Run

1. Install Python.
2. Install required libraries:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
